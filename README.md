# תמונות לחומרים של אחיה

העמוד הראשון של כל חומר מאתר אחיה, לכרטיסים בקטלוגים של הקול החמישי. הצילום נעשה בשרת של GitHub ולא במחשב הבית.

- `todo.json`: החומרים שצריך לצלם. נכתב מהמחשב על ידי `catalog-kit/achiya_cloud.py`.
- `ach/<id>.webp`: התמונות.
- `failed.json`: חומרים שאין להם תמונה (אין קובץ בעמוד, Word ישן ועוד). לא מנסים אותם שוב.

שינוי ב-`todo.json` מפעיל את הצילום אוטומטית. הוא נעשה **בקשה אחת בכל פעם**, עם הפסקות, כי זה האתר של מישהו אחר.
